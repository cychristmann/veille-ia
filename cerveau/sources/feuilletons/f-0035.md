# Feuilleton : Apple menacé d’amende en Corée du Sud pour publicité mensongère sur fonctions IA

Statut : actif · Du 2026-11-20 au 2026-11-27 · Régions : Chine, France, États-Unis

L’Autorité coréenne sanctionne Apple pour avoir exagéré les capacités IA de ses produits, risquant une lourde amende.

## Épisodes

- 2026-11-20 : Plusieurs fuites et offres d'emploi révèlent qu'Apple prépare un agent IA complet capable de piloter des appareils, des applications et le web.
  - Apple prépare son propre agent IA capable de contrôler votre Mac et vos applications (Mac4Ever)
  - Apple préparerait son propre agent IA complet pour concurrencer ChatGPT (Clubic)
  - Apple travaille sur un agent IA capable de piloter vos appareils, vos apps, le web et le code (MacGeneration)
  - Apple construit-elle un agent IA ? Une offre d'emploi décrit un agent qui utilise des apps, navigue et écrit du code (Nacionale)
  - Apple préparerait son propre agent IA complet (Gizmodo)
- 2026-11-27 : Apple risque une lourde amende en Corée du Sud pour publicité mensongère sur des fonctions IA.
  - Apple risque une lourde amende en Corée du Sud pour publicité mensongère sur des fonctions IA (新浪财经_金融信息服务商)
