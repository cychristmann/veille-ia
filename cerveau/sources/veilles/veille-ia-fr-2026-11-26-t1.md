# Veille France 2026-11-26 : Infrastructure et matériel

Région : France · Date : 2026-11-26

Les titres décrivent le déploiement d’infrastructures massives (satellites, data‑centers, puces) et les contraintes liées aux fournisseurs pour supporter l’IA.

- **Starmind : la FCC donne son feu vert à un million de satellites d’IA de SpaceX** (ZDNet, note 8/10)
  Produire l’énergie là où le Soleil brille presque sans interruption et calculer sur place : le régulateur américain des télécoms a autorisé ce projet de SpaceX, une première pour un centre de données en orbite.
- **Une offre exceptionnelle de puces d'IA Nvidia de pointe inonde le marché, les vendeurs cherchant de nouveaux acheteurs après le durcissement des restrictions américaines, visant les entreprises chinoises** (Developpez.com, note 7/10)
- **Nvidia cesse les livraisons de serveurs IA vers quatre pays d’Asie du Sud-Est** (Investing.com France, note 7/10)
- **Epochal lance Time Portal pour entraîner l’IA à prévoir** (Brief IA, note 5/10)
  Time Portal donne aux agents d’IA accès au Web d’une date passée. Le fonds comprend plus de 1 000 milliards de pages sur 30 ans. Un test interactif est proposé avec une liste d’attente.
